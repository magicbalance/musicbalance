YouTube · 영상 받기도우미 확인 전
처음 한 번: PC 도우미 켜는 방법
  1. PC에 Python을 설치해요 (python.org).
  2. 아래 도우미 파일 받기를 눌러 bm_helper.py를 받고, 이 앱 파일(index.html)과 같은 폴더에 둬요.
  3. 그 폴더에서 터미널(명령 프롬프트)을 열고 python bm_helper.py 를 실행해요. 처음엔 필요한 프로그램(yt-dlp, ffmpeg)을 자동으로 설치해요.
  4. PC 브라우저에서 http://localhost:8765 를 열면 이 앱이 열려요. 거기서 주소를 넣고 MP4/WAV 받기를 누르면 목록에 바로 들어와요.
