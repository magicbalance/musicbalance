악보 파일 (MIDI)

.mid 파일을 불러오면 악보가 그려지고, 악보대로 연주도 할 수 있어요.

곡에 맞춰 보려면 곡의 첫 박에서 "여기가 1박"을 눌러주세요. 악보 연주는 속도와 조 바꾸기 설정을 그대로 따라요. 검은색 음표는 악보 파일, 주황색 음표는 실시간으로 인식한 음이에요.

재생 중인 곡의 멜로디(한 번에 한 음)를 실시간으로 듣고 4/4박자 큰보표에 그려요. 건반으로 친 음도 같이 표시돼요. 여러 악기가 섞인 곡은 정확하지 않을 수 있어서, 이럴 땐 "반주 삭제"로 보컬을 강조하면 더 잘 잡혀요. 박자를 맞추려면 BPM을 곡에 맞게 바꿔주세요.

주소로 내려받기

mp3, mp4 같은 파일을 직접 가리키는 주소를 넣으면 내려받아서 바로 재생하고, 기기에 저장할 수 있어요.

내가 만들었거나 사용 권한이 있는 파일만 받아주세요. 유튜브·스포티파이 같은 스트리밍 페이지 주소는 지원하지 않고, 서버가 외부 접근을 막은 파일은 불러올 수 없어요.

처리한 소리로 저장

지금 설정(속도, 조, 보컬/반주, 마스터링)을 그대로 적용해서 WAV 파일로 만들어요.

긴 곡은 메모리를 많이 써서 아이폰에서 실패할 수 있어요. 5분 이내 곡을 권해요.
